# Testing Strategy

**Version:** 0.1  
**Status:** Under Development

## 1. Purpose

Make sure the game works properly, find bugs, and improve the gameplay experience.

## 2. What We Test

- Player movement and combat.
- Inventory and crafting.
- Infected behaviour.
- NPC interactions.
- Weather and temperature.
- Saving and loading.
- Performance and browser compatibility.

## 3. Types of Testing

- **Manual Testing:** Playing the game and checking features yourself.
- **Automated Testing:** Using code to check if systems work.
- **Playtesting:** Getting other people to play the game and share their feedback.
- **Performance Testing:** Checking how smoothly the game runs.
- **Bug Testing:** Finding and fixing problems.

## 4. Playtesting

During playtests, we want to find out:

- Is the game fun?
- Are the controls easy to understand?
- Are the survival mechanics enjoyable?
- Are there any confusing features?
- Is the game too easy or difficult?
- Did anything break during gameplay?

Playtesters should be encouraged to give honest feedback.

## 5. Bug Reports

When a bug is found, record:

- What happened?
- Where did it happen?
- How can it be reproduced?
- What should have happened?
- How serious is it?

## 6. Bug Priorities

- **Critical:** Crashes, broken saves, or game-breaking bugs.
- **High:** Major features not working.
- **Medium:** Noticeable gameplay issues.
- **Low:** Small visual or minor bugs.

## 7. Before an Update

- [ ] Test new features.
- [ ] Fix major bugs.
- [ ] Check older features still work.
- [ ] Test saving and loading.
- [ ] Check performance.
- [ ] Run playtests when needed.

## 8. Before Alpha v0.1.0

- [ ] Test the main gameplay.
- [ ] Test survival mechanics.
- [ ] Test combat and infected AI.
- [ ] Test NPC interactions.
- [ ] Test inventory and crafting.
- [ ] Test weather and temperature.
- [ ] Test saving and loading.
- [ ] Run external playtests.
- [ ] Fix major bugs.

*ULTIMA AETAS is under early development. All systems and procedures are subject to change.*
